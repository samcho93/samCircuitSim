# ⚡ samCircuitSim — 혼합 신호(아날로그 + 디지털) 회로 시뮬레이터

**아날로그 부품과 디지털 부품을 한 회로에 섞어 설계하고 바로 시뮬레이션**하는 웹 회로 시뮬레이터입니다.
[회로이론 강좌(studyCircuit)](https://samcho93.github.io/studyCircuit/)의 아날로그 시뮬레이터와
[디지털 공학 강좌(studyDigital)](https://samcho93.github.io/studyDigital/)의 디지털 시뮬레이터를 하나의 엔진으로 합쳤습니다.

👉 **https://samcho93.github.io/samCircuitSim/**

설치 · 서버 · 외부 라이브러리 없이 정적 파일만으로 동작합니다.

## 무엇을 할 수 있나

- 555 타이머의 RC 충방전(아날로그)이 만든 클럭으로 10진 카운터(디지털)를 세고 7세그먼트에 표시
- 카운터 → **D/A 변환기** → RC 필터 → 오실로스코프, 가변저항 → **A/D 변환기** → 16진 표시
- 논리 게이트 출력이 실제 전류를 흘려 LED 를 켜고, **CMOS 인버터**(MOSFET)를 논리 스위치로 구동
- 인버터 입력의 **문턱값 히스테리시스**와 RC 만으로 발진기 만들기, **비교기** · **아날로그 스위치** · **릴레이**
- **전원 회로**: 변압기 + 브리지 + 7805 AC-DC 전원, AC-DC SMPS 모듈, 벅 · 부스트 컨버터 원리(개루프), LM2596 · MT3608 스위칭 레귤레이터(폐루프), DC-DC 모듈의 효율
- **정전압**: LM317 가변, AMS1117 LDO 드롭아웃, TL431 션트, OP앰프 + 트랜지스터 직렬 레귤레이터 / **정전류**: LM317 LED 드라이버, OP앰프 + MOSFET 전자 부하, 트랜지스터 2개 전류 제한, TP4056 리튬 충전(CC → CV)
- 물론 순수 아날로그(정류 · 증폭 · 발진 · 필터) 회로와 순수 디지털(게이트 · 플립플롭 · 카운터 · 메모리) 회로도 그대로

## 혼합 신호 엔진

```
js/sim/analog.js   아날로그 코어: 수정 마디 해석(MNA) + 부분 피벗 LU + 사다리꼴/후진 오일러 + 뉴턴-랩슨
                   (다이오드 지수 모델 · 에버스-몰 BJT · 제곱 법칙 FET · tanh 포화 + GBW OP앰프 · 결합 인덕터 …)
js/sim/digital.js  디지털 코어: 이벤트 구동(0 · 1 · X · Z), 관성 지연, 에지 트리거, 부품 동작
js/sim/engine.js   두 코어를 하나로: 회로 텍스트 · 연결(넷) · 경계 브리지 · 시간 진행 · 측정
```

1. **연결** — 모든 단자와 도선 끝점을 점으로 모아 넷을 만듭니다 (도선 중간에 닿은 단자 · 같은 이름표 · 접지 포함).
   아날로그 단자가 하나라도 닿은 넷은 **아날로그 넷**(MNA 마디), 디지털 단자만 닿은 넷은 **디지털 넷**(논리값)입니다.
2. **경계 브리지**
   - 디지털 출력 → 아날로그 넷: **출력 저항(기본 25 Ω) + 목표 전압(0 V / VDD)** 의 노턴 등가. Z(끊김)면 연결을 끊습니다.
     풀업/풀다운은 10 kΩ, VCC/GND 기호는 0.5 Ω, D/A 출력은 코드에 비례한 전압.
   - 아날로그 넷 → 디지털 입력: **문턱값 히스테리시스** (0.6·VDD 위로 올라가면 1, 0.4·VDD 아래로 내려가면 0).
   - 비교기 · 555 · A/D 변환기는 아날로그 단자 전압을 직접 읽습니다 (555 의 CV 단자는 내부 5k-5k-5k 분압을 흉내 낸 ⅔·VCC, 3.3 kΩ).
3. **시간 진행**
   - 콘덴서 · 코일 · 변압기 · 교류 전원 · OP앰프처럼 상태가 있는 아날로그 소자가 있으면 **lockstep**: 디지털 사건을 시각 t+dt 까지 처리 → 브리지 갱신 → 아날로그 한 단계 → 문턱값 → 디지털 입력.
   - 없으면 **event**: 디지털 사건(나노초 단위 게이트 지연)이 생길 때마다 아날로그를 다시 풉니다 (저항 · LED · 트랜지스터는 순간 응답).
   - 아날로그가 없으면 순수 디지털 사건 구동.

## 회로 텍스트

한 줄에 부품 하나. 좌표는 격자 칸(20 px).

```
$ dt=1m vdd=5                  # 옵션: 시간 간격, 논리 전원, speed, ic=zero, method=be, rout, vih, vil
V 0 14 0 -4 9                  # 두 점 부품: 종류 x1 y1 x2 y2 값   (전원은 첫 점이 −)
R 6 -4 6 4 10k name=RA lp=l
C 6 8 6 14 10u pol=1
T555 10 4                      # 한 점 부품: 종류 x y [rot=0~3] [f=1]
CNT 21 6 mod=10 name=CNT
AND 9 5 n=3 d=10n
CLK 2 2 freq=10
W 0 -4 15 -4                   # 도선
P 6 8 VC                       # 측정점
N 30 4 DATA                    # 이름표 (같은 이름끼리 연결)
scope ch1=VC ch2=OUT tb=0.5 v1=2 v2=5
la ch=CK,Q3(CNT),Q0(CNT)       # 로직 분석기 채널
! t=3 VMAX(VC)=6 tol=6%        # 검사식 (아날로그): 시각 t 의 값 · 통계
! A=1 B=0 -> Y=1 V(Y)=4.8      # 검사식 (디지털): 입력을 정하고 안정된 뒤 확인
```

회로이론 강좌 · 디지털 강좌의 회로 텍스트도 그대로 읽습니다 (`LED x y` → 로직 LED, `PB x y` → 논리 버튼, `CLK f=2` → `freq=2`).
